# منصة تعلّم كلاود

منصة تعليمية عربية تفاعلية لتعلّم استخدام Claude من الصفر — خمس مراحل متدرجة، ورشة تطبيق عملي بستة مجالات، وصفحات مرجعية.

## المحتوى

- **خمس مراحل:** الأساسيات، كتابة الأوامر، الأدوات والمخرجات، المهارات والأتمتة، المستوى التقني — كل مرحلة فيها دروس واختبار وتمرين عملي.
- **ورشة التطبيق العملي:** البرمجة، قواعد البيانات، المشاريع المتكاملة، التصميم، المونتاج، والإنتاج التعليمي — مع مقارنة بين طلب ضعيف وطلب قوي بنصّه الكامل.
- **المرجع العملي:** الربط بالتطبيقات (MCP)، المهارات، الإضافات، والموديلات.

المحتوى مبني على التوثيق الرسمي لأنثروبيك.

## التشغيل

صفحة واحدة مستقلة بدون أي اعتماديات — افتحي `index.html` مباشرة، أو زوري النسخة المنشورة على GitHub Pages.
